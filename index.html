Projects
Lingo: AI Chrome Extension for Real-time Slang & Cultural-Reference Learning
Startup project, Apr. 2025 – Present

Lingo helps non-native English speakers pick up slang, phrasal verbs, cultural references, and wordplay while watching YouTube, with real-time AI term detection and explanations rendered directly on the video. I led the project from ideation to launch: curated a 122GB raw + synthetic benchmark and built the data-to-eval pipeline to select cost-effective open-source and API models, trained a lightweight in-house slang-detection model as a baseline, and engineered the production stack (React + TypeScript front end, FastAPI + PostgreSQL back end, Dockerized on GCP with CI/CD to the Chrome Web Store).
